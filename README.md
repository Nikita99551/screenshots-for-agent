# Скриншоты для агента

Программа для Windows: делаешь серию скриншотов, на каждом ставишь стрелку или рамку и пишешь
(или говоришь голосом) комментарий. Потом одна кнопка — и всё попадает в буфер обмена:
картинки с номерами и подписями плюс текст «1. … 2. … 3. …». Вставляешь в чат с ИИ (Claude, ChatGPT, Cursor)
через Ctrl+V, и агент сразу понимает, что и где исправить.

## Установка

1. Скачай `Screenshots-for-Agent-Setup-….exe` из раздела [Releases](../../releases).
2. Запусти. Windows может показать «Система Windows защитила ваш компьютер»: программа не подписана
   платным сертификатом. Нажми «Подробнее» → «Выполнить в любом случае».
3. После установки в правом нижнем углу появится маленькая панель, а в трее — оранжевый кружок.

При первом запуске программа сама скачает модель распознавания речи (около 220 МБ). Пока она качается,
голосовой ввод недоступен, всё остальное работает. Дальше интернет для голоса не нужен.

## Как пользоваться

| Действие | Клавиши |
|---|---|
| Новый снимок | `Ctrl+Shift+S` |
| Показать / скрыть панель | `Ctrl+Shift+D` |
| Стрелка, рамка, номер, карандаш | `A`, `R`, `N`, `P` |
| Цвет | `1`–`8` |
| Голосовой ввод комментария | `Ctrl+Пробел` (нажал — говоришь — нажал ещё раз; или держи, как рацию) |
| Сохранить снимок | `Enter` |
| Отменить | `Esc` |

Панель — маленькая «пилюля»: счётчик снимков, кнопка «скопировать всё» и стрелка, которая раскрывает список.
В списке можно поменять порядок, исправить комментарий, заново открыть разметку или удалить снимок.

После «скопировать всё» нажми `Ctrl+V` в чате: вставятся картинки, а следом программа сама вставит текст
с комментариями (некоторые чаты берут из буфера только картинки, поэтому текст идёт вторым шагом).
Подпись к каждому снимку также дорисована под картинкой.

## Конфиденциальность

Всё работает на твоём компьютере. Снимки, комментарии и голос никуда не отправляются: распознавание речи
выполняет локальная модель. Сеть нужна только один раз — скачать эту модель.
Данные лежат в `%APPDATA%\screenshots-for-agent`.

## Как это устроено

- Electron: панель, окно выделения и редактор разметки.
- Снимок экрана — постоянный помощник на PowerShell/C# (GDI), около 40 мс.
- Распознавание речи — [GigaAM v3](https://github.com/salute-developers/GigaAM) (Сбер, русский язык, с пунктуацией)
  через [onnx-asr](https://github.com/istupakov/onnx-asr), встроенный Python 3.12. Фраза в 10 секунд — меньше секунды на обычном процессоре.

## Сборка из исходников

Нужны Node.js 20+ и Python 3.12 (`py -3.12`).

```bash
npm install
npm run python   # встраиваемый Python с библиотеками распознавания в build/python
npm run icon     # иконка build/icon.png
npm run dist     # установщик в dist/
```

Для разработки без сборки: создай окружение `py -3.12 -m venv stt/.venv`, поставь в него
`pip install "onnx-asr[cpu,hub]" numpy` и запусти `npm start`.
